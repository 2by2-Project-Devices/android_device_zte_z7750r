Device configuration for ZTE Axon 31 5G
=========================================

The ZTE Axon 31 5G (codenamed _"tenet"_) is a middle-end smartphone from ZTE.

It was announced in April 2021. Release date was May 2021.

## Device specifications

Basic   | Spec Sheet
-------:|:-------------------------
SoC     | Qualcomm SM7250-AC Snapdragon 768G 5G (7 nm)
CPU     | Octa-core (1x2.8 GHz Kryo 475 Prime & 1x2.4 GHz Kryo 475 Gold & 6x1.8 GHz Kryo 475 Silver)
GPU     | Adreno 620
Memory  | 8 GB RAM
Shipped Android Version | 11 with MyOS 11
Storage | 128/256 GB
Battery | Non-removable Li-Ion 4200 mAh battery
Display | 1080 x 2400 pixels, 20:9 ratio, 6.67 inches, AMOLED (~395 ppi density)
Rear Camera  | 64MP (wide) / 8MP (ultrawide) / 2 MP (macro) / 2 MP (depth)
Front Camera | 44MP (wide)
